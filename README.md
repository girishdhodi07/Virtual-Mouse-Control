# 🖱️ Virtual Mouse Control

A real-time Virtual Mouse Control system using hand gestures.

Control the computer mouse cursor using your **Index Finger** and perform a **Left Click** using a **Thumb + Index Finger Pinch Gesture**.

## 🚀 Features

- 🖱️ Real-time mouse cursor control
- ☝️ Index finger based cursor movement
- 🤏 Thumb + Index finger pinch for left click
- 🎯 Active camera interaction boundary
- 🔄 Smooth cursor movement
- ✋ Real-time hand tracking
- 📷 Webcam based interaction

## 🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe
- PyAutoGUI
- Math

## ⚙️ How It Works

```text
Webcam
   ↓
Hand Detection
   ↓
MediaPipe Hand Tracking
   ↓
Index Finger Tracking
   ↓
Cursor Movement
   ↓
Thumb + Index Finger Pinch
   ↓
Left Mouse Click
